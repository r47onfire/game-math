# game-math

library of math useful for games and applications!

designed to be run through a dead-code eliminator - all classes have no methods (where practical). functions you do not use will be dead-code eliminated entirely.

mostly copied from various places on the internet:

* linear algebra, geometry, colors, graphs, random, AI - from [KAPLAY](https://github.com/kaplayjs/kaplay) (thanks @mflerackers the bean wizard and other contributors)
* data structures (linked list, AVL tree) - from me, based on an implementation in *Data Structures and Abstractions with Java*, 5th Edition. I forget where I got the interval tree stuff.
